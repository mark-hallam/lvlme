# Inbox

This is the only file in the workspace that other agents (and you) may write
to. Add a note under "New". The next run checks each note against its source,
then moves it to "Processed" with a one-line outcome. A note on its own is not
evidence: facts count only once their source has been checked.

Note format, one bullet per note:

```
- <YYYY-MM-DD> | <who: you, or the agent's name> | <the note> | <source: a link, file or email reference>
```

Example:

```
- 2026-11-02 | research agent | Acme AI posted a new program role in Sydney | https://jobs.example.com/acme/123
```
